# Biblioteca CRUD

Proyecto grupal: aplicación CRUD para la gestión de una biblioteca.

## Descripción

Desarrollaremos una aplicación que permitirá crear, leer, actualizar y eliminar registros relacionados con la biblioteca (libros, usuarios, préstamos, etc.).

## Herramientas

- Liquibase para el control de versiones de la base de datos.
